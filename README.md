# Olympic Shooting Stats

A project to record and display statistics for Olympic shooting events.

## Goals

- Record results from Olympic shooting competitions (qualification and finals).
- Store athlete, country and event information in one place.
- Show statistics through tables and charts: medal counts, scores, records and trends over time.

## Disciplines covered

| Discipline | Events |
|------------|--------|
| Rifle      | 10m Air Rifle, 50m Rifle 3 Positions |
| Pistol     | 10m Air Pistol, 25m Pistol, 25m Rapid Fire Pistol |
| Shotgun    | Trap, Skeet |

Men's, women's and mixed team events are included.

## Planned features

- [ ] Data model for athletes, countries, events, Games and results
- [ ] Import results from CSV files
- [ ] Manual entry of new results
- [ ] Medal table by country and by athlete
- [ ] Score history and personal bests per athlete
- [ ] Olympic and world records tracking
- [ ] Charts comparing athletes, countries and editions of the Games
- [ ] Search and filters (year, discipline, event, gender, country)

## Data

Each result record will contain at least:

- Games (year and host city)
- Discipline and event
- Athlete and country
- Phase (qualification / final)
- Score and final rank
